# 🧠 DSA Prep

LIVE AT https://dsa-prep-sooty.vercel.app/

> **Master the patterns. Track the progress.**

**DSA Prep** is a personal Data Structures & Algorithms preparation dashboard designed to help you organize, solve, and track your DSA journey in one place.

It combines a curated **269-question DSA dataset** based on NeetCode 150 + Striver patterns with progress tracking, personal notes, priorities, custom lists, mood-based recommendations, and a modern glassmorphism interface.

🔗 **GitHub:** https://github.com/Abhishek-singh06/dsa-prep

---

## ✨ Features

### 📊 Personal DSA Dashboard

Track your preparation with:

* Overall completion percentage
* Completed / remaining questions
* Current streak
* Questions completed today
* Circular progress visualization
* Category-wise progress
* DSA coverage heatmap

### 🎯 Today's Mission

Get a focused set of questions to work on, prioritizing high-priority incomplete problems, your personal list, foundational patterns, and remaining questions.

### ✅ Question Tracking

Every question supports:

* Completion tracking
* ⭐ Priority
* 💬 Personal comments / notes
* 🔖 Add to My List
* Question status
* Direct platform links

Priority levels:

* 📚 Basic
* ⭐ Important
* 🔥 High Priority

### 🔗 Multiple Resources

Questions can include verified links to:

* LeetCode
* NeetCode
* Striver / takeUforward
* YouTube

### 📚 My List

Create your personal revision queue and organize questions into:

* 🔥 High Priority
* ⭐ Important
* 📚 Basic

### 🎭 Mood Mode

Choose what you feel like solving:

* 🟢 **Easy** — Warm up
* 🟡 **Normal** — Keep building
* 🔴 **Grind** — Push yourself
* ⚡ **Random** — Surprise me

### 🔎 Search & Filters

Search and filter questions by:

* Problem name
* Category
* Source
* Priority
* Completion status

### 📈 17 DSA Categories

The application contains **269 unique questions** across:

* Arrays & Hashing
* Two Pointers
* Sliding Window
* Stacks & Queues
* Binary Search
* Linked Lists
* Binary Trees & BSTs
* Heaps & Priority Queues
* Recursion & Backtracking
* Tries
* Graphs: Traversal & Connectivity
* Graphs: Paths & Spanning Trees
* Dynamic Programming
* Greedy & Intervals
* Math & Geometry
* Bit Manipulation
* String Matching

## 💾 Local-First

DSA Prep currently works without a backend or database.

Your personal data is stored locally in the browser using `localStorage`.

This includes:

* Completed questions
* Comments
* Priorities
* Question status
* My List
* Custom lists
* Streak history
* Last interacted question

The application also supports JSON export/import for backups.

